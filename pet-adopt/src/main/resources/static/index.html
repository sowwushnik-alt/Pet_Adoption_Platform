Pet Adoption Platform API

The application is running successfully. Currently, it provides the following API endpoints:

  • GET /api/pets/ - Retrieve all pets
  • GET /api/pets/{id} - Retrieve a specific pet by ID
  • POST /api/pets/ - Create a new pet (JSON body required)
  • DELETE /api/pets/{id} - Remove a pet record

Try visiting /api/pets/ to see the current pet list.
